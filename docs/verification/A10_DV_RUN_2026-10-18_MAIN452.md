# A10 DV selected current-main replay — 2026-10-18

## Baseline and scope

This run replays selected suites on GitHub `main` across three documentation-
only SHAs: FP, Control, DMA, and top-smoke gates ran at `452813f`; CP/Completion
coverage ran at `ebeffd8`; and DMA–SPAD subsystem coverage ran at `32d408b`.
RTL and checked-in test sources were unchanged across these SHAs. The Rocky
bridge task file was local/untracked and is not part of the project or evidence
commits.

Environment: Rocky Linux 8.10, VCS/URG `V-2023.12-SP1_Full64`. Simulation and
coverage artifacts are local under `/tmp/nmaforge_a10_*` and the ignored
subsystem `coverage/` directory; they are not checked into Git.

## Reproduction

From the repository root in Rocky/WSL:

```sh
make -C dv/block/compute/fp/sim dot-uvm-regress \
  DOT_RANDOM_COUNT=200 \
  DOT_UVM_SEEDS='712345 987654 20261015' \
  DOT_UVM_OUT_DIR=/tmp/nmaforge_a10_main452_fp_20261018 \
  VCS='vcs -licwait 1'
(cd dv/block/compute/fp/model && python3.12 -m unittest -v test_fp_reference.py)

make -C dv/subsystem/top_smoke/sim ai_smoke
make -C dv/subsystem/top_smoke/sim ai_run AI_RANDOM_CASES=20 AI_SEED=12345

make -C dv/block/command_processor/uvm cov-regress \
  SEEDS='20261040 20261041 20261042' \
  MIXED_COV_CASES='1-0 1-1 1-3 2-0 2-1 2-3' \
  OUT=/tmp/nmaforge_a10_main_ebeffd8_cp_coverage_20261018 \
  VCS='vcs -licwait 1' URG=urg

make -C dv/subsystem/dma_spad/sim subsystem_regress \
  SEEDS='20261050 20261051 20261052' \
  COV_TAG=a10_main32d408b_20261018 \
  URG_REPORT=/tmp/nmaforge_a10_main32d408b_v3_20261018/urg_merged \
  VCS='vcs -licwait 1' URG=urg SIMV=simv_a10_main32d408b_20261018
```

ran their complete named-test lists in isolated `/tmp` simulator/VDB
