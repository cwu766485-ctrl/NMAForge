## Reproduction commands

Commands below were run from the repository root in the detached worktree;
output paths shown are the isolated artifact paths above.

```sh
artifact_root=/tmp/nmaforge_a10_main2166334_v1fp_20261019

make -C dv/block/compute/fp/sim dot-core-test \
  DOT_CORE_OUT_DIR=$artifact_root/dot_core \
  DOT_CORE_PARITY_MAX_OUT_DIR=$artifact_root/max_parity \
  VCS='vcs -licwait 1'

make -C dv/block/compute/fp/sim dot-uvm-regress DOT_RANDOM_COUNT=200 \
  DOT_UVM_SEEDS='712345 987654 20261015' \
  DOT_UVM_OUT_DIR=$artifact_root/uvm VCS='vcs -licwait 1' URG=urg

(cd dv/block/compute/fp/model && python3.12 -m unittest -v test_fp_reference.py)

make -C dv/block/dma/sim uvm_regress \
  SIMV=../../../../../nmaforge_a10_main2166334_v1fp_20261019/dma_official_retry/simv_dma \
  COV_ROOT=$artifact_root/dma_official_retry/coverage VCS='vcs -licwait 1'
make -C dv/block/dma/sim coverage \
  COV_ROOT=$artifact_root/dma_official_retry/coverage URG=urg

make -C dv/block/control/sim uvm_regress \
  SIMV=../../../../../nmaforge_a10_main2166334_v1fp_20261019/control_official_retry/simv_control \
  COV_DIR=$artifact_root/control_official_retry/coverage.vdb VCS='vcs -licwait 1'
make -C dv/block/control/sim coverage \
  COV_DIR=$artifact_root/control_official_retry/coverage.vdb URG=urg

make -C dv/subsystem/top_smoke/sim ai_smoke SEED=20261019
make -C dv/subsystem/top_smoke/sim ai_run \
  AI_RANDOM_CASES=20 AI_SEED=12345 SEED=20261019
```

The block Makefiles invoke `./$(SIMV)`, so `SIMV` must be relative to each
simulation directory. An initial attempt passed an absolute path and failed
before simulation; it was corrected before the passing official regressions.
An exploratory manually merged coverage database also produced an invalid URG
design-load result and is discarded; only the official Makefile-generated
coverage reports above are retained as evidence.
