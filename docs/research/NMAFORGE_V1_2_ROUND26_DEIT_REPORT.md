# NMAForge-V1.2 Round 26 — DeiT Track Report

## Disposition

**Full 197-row Q/K/V Product Top projection: PASS. One complete three-head 16-query × 197-key QK→Softmax→AV Product Top block: PASS. Full Encoder Layer 0: PARTIAL / NOT RUN.**

Round 26 extends the DeiT path beyond the prior single-head/partial-query evidence. The selected local official `facebook/deit-tiny-patch16-224` checkpoint was used to generate Q/K/V projection operands. The 197-row LayerNorm result is from the archived Round 24 Product Top run; the new Round 26 Product Top run computes all three Q/K/V projections from that verified readback. A second Product Top run consumes Golden-checked Q/K/V readbacks, performs all three heads' QK, one 197-valid-key Softmax per query, probability packing, and AV for Query 0–15.

These are **two staged Product Top runs**, with explicit host readback/repacking and DMA between them. They are not a continuous single-session Encoder Layer. Output Projection, residuals, LN2, FFN/GELU, all 197 query rows, and classification remain open. No product compute RTL or ABI was changed.

## First attempt and bounded fix

The first full Q/K/V Top replay stopped before the first descriptor because the testbench AXI memory had only 12,288 words while the generated DMA payload had 28,224 words. VCS reported `$readmem` overflow at payload entry 12,289 and an invalid late-DMA event 62 (`ext=0x0000bfc0`, 256 words). This was a testbench backing-memory capacity issue, not a DUT calculation mismatch.

The Round 26 testbench's `AI_REPRESENTATIVE_LONG_TASK` AXI storage was increased to 32,768 words, and the representative descriptor/queue parser bound was raised from 512 to 768 for the 735-descriptor workload. The descriptor Validator was not relaxed. Re-running Q/K/V passed; the attention run also passed. This sizing change is testbench-only and does not alter product RTL.

VCS compile logs include the existing `Warning-[LOOP-REROLL-ENABLED]`; the focused changes introduced no new RTL warning. Do not interpret that pre-existing compile warning as a signoff-clean lint result.

The required baseline `make ai_smoke` also exited 0 and ended with `TEST PASS`; its compile and simulation logs are archived under `benchmark/deit/round26/evidence/smoke/`. The smoke includes existing GEMV, fused forwarding, CNM, protection, and reset-recovery checks.
